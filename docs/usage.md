# 使用说明

## 找到文件改动

1. 运行 `codex-changes`。如果当前目录是已有历史的项目，或位于该项目的子目录中，会直接显示这个项目的会话列表；选择会话时自动读取修改记录。嵌套项目选择路径最接近的一层，但不会把 home 或文件系统根目录当作所有子目录的通用项目。
2. 如果当前目录没有关联历史，则显示全局项目列表。`--thread` 和 `--file` 优先于目录定位，可直接打开指定会话和文件。
3. 按 `/` 或 `f` 筛选当前高亮栏：项目层筛项目，会话层跨项目搜索会话，目录、文件、修改记录和差异块层也各自筛选本层。Enter 接受筛选，Esc 清除；操作不会跳到右侧其他层级。
4. 进入会话后依次选择目录、文件、修改记录和差异块。目录仅按历史路径分组，不读取当前文件系统。
5. 右侧即时显示选中差异块的 diff，按 `J` / `K` 可直接滚动预览。按 `c` 可切换为所选文件的完整连续时间线，再按一次返回单块模式。

界面采用逐级展开的米勒列布局，同屏最多三栏。空间不足时先收起最左侧层级；窄于 90 列时只显示当前层级或 diff。非搜索状态下，按键遵循 Yazi 的核心导航习惯：`h` / 左方向键返回，`l` / 右方向键进入，`j` / 下方向键选择下一项，`k` / 上方向键选择上一项。Tab 仍用于在可见区域间切换。

父栏和当前栏根据可见行的名称、行信息和中文显示宽度收缩，剩余空间全部给最右侧预览，无论预览显示目录、文件还是 diff。窗口变宽时，内容未变的父栏和当前栏保持原宽度；隐藏行信息后，回收的空间也交给右侧预览。滚动列表、切换信息或调整窗口后会重新分配列宽；空间不足的长内容用省略号表示。

长会话逐页读取，已发现的文件可以提前查看。程序退出时记住所选会话、文件和显示偏好；下次启动只在当前目录对应的项目内复用这些选择，不会绕过目录定位直接打开旧 diff。重新启动仍会重新读取历史，不保存差异正文缓存。

## 阅读差异

绿色底色表示新增，红色表示删除；底色会铺满行宽。相邻的删除与新增行会逐行配对，深一些的底色标出变化的词语。变化超过一对文本的 40% 时只保留整行提示；新建、删除和没有配对的行也只使用整行提示。

新增代码与上下文使用语法配色，删除代码保留普通文字颜色。单栏只显示一列行号：删除行取旧文件行号，新增与上下文取新文件行号。并排时左侧是旧内容，右侧是新内容。折行显示 `↳`，不重复行号。

语言按历史文件名识别；语法分析只使用补丁已有的上下文，不读取当前文件。缺少上下文、未知语言或过大的代码片段可能显示普通文字，差异正文仍会完整保留。中文按字符比较，代码标识符按词语比较；组合字符和表情不会被高亮或换行拆开。

查看包含 SVG、TypeScript 和 JSON 的演示：

```bash
codex-changes --demo --thread demo-diff --file overview.svg
```

## 操作

| 序号 | 操作 | 按键或鼠标 |
| --- | --- | --- |
| 1 | 切换会话 | `s`；也可点击顶端标题 |
| 2 | 筛选当前高亮栏 | `/` 或 `f` 进入筛选后输入；Enter 接受；Esc 清除 |
| 3 | 进入、返回层级 | Enter / `l` / 右方向键；Esc / `h` / 左方向键 |
| 4 | 切换可见区域 | Tab / Shift+Tab |
| 5 | 清除当前栏筛选 | Esc；没有筛选时 Esc 返回上一级 |
| 6 | 选择项目、会话、目录、文件或修改 | `j` / `k` 或方向键；鼠标点击；选中会话后自动加载 |
| 7 | 滚动 diff 预览 | `J` / `K`，无需切换焦点；聚焦 diff 后也可用方向键或 `j` / `k` |
| 8 | 翻页 | Page Up / Page Down 或 Ctrl+B / Ctrl+F 翻整页；Ctrl+U / Ctrl+D 翻半页；搜索时 Ctrl+U 清空输入 |
| 9 | 到开头、末尾 | `g` / `G`，或 Home / End |
| 10 | 跳到上一条、下一条修改 | `[` / `]` |
| 11 | 单块 diff、连续时间线 | `c` |
| 12 | 折叠、展开修改 | 连续模式中点击修改标题，或按 Space |
| 13 | 单栏、并排差异 | `v`；空间不足时自动使用单栏 |
| 14 | 自动换行 | `w`；关闭后在 diff 中用左右方向键横向滚动 |
| 15 | 隐藏、显示导航 | `b` |
| 16 | 主题 | `t`：跟随终端 → 深色 → 浅色 |
| 17 | 复制文件完整路径 | `y` |
| 18 | 重新读取当前会话 | `r`；项目或会话层改为刷新当前列表 |
| 19 | 刷新会话列表 | Ctrl+R |
| 20 | 帮助 | 非搜索层按 `?`；Esc 或 `?` 关闭 |
| 21 | 退出 | 非搜索层按 `q`；Ctrl+C 在所有界面中均有效 |
| 22 | 当前栏排序 | `,` 打开菜单，再按对应字母；小写升序、大写降序；`d` 恢复默认顺序 |
| 23 | 当前栏行信息 | `m` 打开菜单，再按对应字母；`a` 恢复默认信息，`n` 隐藏行信息 |

建议至少 100 列、24 行；最小支持 40 列、10 行。要显示“修改记录、差异块、diff”三栏并保留足够代码宽度，建议使用更宽的终端。

复制路径在 macOS 使用 `pbcopy`，其他环境通过终端的 OSC 52 协议发送。后者取决于终端及 tmux 的剪贴板设置。启用鼠标的 tmux 会将应用区域里的鼠标事件交给程序；终端原有的文本选择操作仍由终端负责。

## 排序与行信息

使用英文输入状态，直接按逗号或小写 `m`，无需 tmux 前缀。菜单只显示当前高亮栏可用的选项，Esc 或 `q` 关闭菜单。筛选输入中的逗号和 `m` 仍作为文字输入；聚焦 diff 时先用 `h` 返回列表，再操作菜单。

| 序号 | 排序按键（依次按下） | 含义 | 适用层级 |
| --- | --- | --- | --- |
| 1 | `, a` / `, A` | 名称升序 / 降序 | 项目、会话、目录、文件 |
| 2 | `, n` / `, N` | 自然名称升序 / 降序，如 `file2` 排在 `file10` 前 | 项目、会话、目录、文件 |
| 3 | `, m` / `, M` | 时间从早到晚 / 从晚到早 | 项目、会话、目录、文件、修改记录 |
| 4 | `, b` / `, B` | 创建或首次修改时间升序 / 降序 | 项目、会话、目录、文件 |
| 5 | `, c` / `, C` | 数量升序 / 降序 | 项目的会话数、目录的文件数、文件的修改次数 |
| 6 | `, s` / `, S` | 新增与删除行数之和升序 / 降序 | 目录、文件、修改记录、差异块 |
| 7 | `, e` / `, E` | 扩展名升序 / 降序 | 文件 |
| 8 | `, d` | 恢复默认顺序 | 所有列表 |

默认顺序为：项目和会话按最近更新优先，目录和文件按名称排列，修改记录按历史顺序（最近修改优先），差异块按补丁中的位置排列。排序保留当前选中项及其下级选择，也适用于筛选结果和后续读入的历史。连续时间线保持原始历史顺序。

`m m` 显示时间，`m b` 显示创建或首次修改时间，`m c` 显示数量，`m s` 显示增删行数；适用层级与上表相同。`m n` 隐藏行尾信息，`m a` 恢复该层级的默认信息。按时间、数量或变更行数排序时，会同时切换到对应信息，便于核对顺序。

所有数据来自已读取的历史：项目时间取其会话的最早创建、最近更新；目录和文件时间取已记录修改的最早、最近时间；修改记录使用轮次时间。目录和文件的首次修改时间不代表磁盘文件的创建时间。没有时间的条目显示“时间未记录”，升序与降序时均排在末尾。加载未完成时，数量和增删行数会随新记录更新。这里的变更行数不表示文件字节大小。

## 启动参数

```bash
# 打开指定会话，并选中文件
codex-changes --thread <thread-id> --file notes.md

# 会话列表包含已归档会话
codex-changes --archived

# 只统计所选会话，不汇总子会话
codex-changes --children=false

# 指定 Codex CLI
codex-changes --codex-bin /path/to/codex

# 忽略已保存的界面偏好，也不保存本次选择
codex-changes --no-state

# 使用合成数据，不访问本机 Codex 历史
codex-changes --demo
```

`--thread` 使用会话 ID，不是会话名称；按名称查找请使用会话选择页。`--file` 可传完整路径或文件名，同名文件建议使用完整路径。

无界面的读取检查：

```bash
codex-changes check --thread <thread-id> --file notes.md
codex-changes check --demo --file 读出时间.md
```

`check` 输出文件数、修改数、轮次数及指定文件的累计增删行数，不输出差异正文。读取错误或找不到指定文件时返回非零退出码。部分子会话读取失败会列在 `warnings` 中，存在该字段时不能把统计当作完整结果。

## 统计范围

- 只纳入 Codex `fileChange` 中 `status=completed` 的修改；失败、拒绝和进行中的操作单独计数并跳过。
- 文件路径可以位于任意目录；无需 `.git`，也无需文件现在仍然存在。
- 默认查询并验证子会话的父子关系，汇总活动及已归档子会话，并标记每条修改的来源。独立会话中的修改不自动混入。
- 同一个文件的多次修改分别保留。`累计 + / −` 是这些记录的行数之和，不是最终文件相对原文件的净变化。
- 新建和删除记录按完整文本展示；更新记录按保存的补丁展示；移动记录保留原路径和后续历史。
- 时间使用所在轮次的开始时间；缺失时使用结束时间。这不是文件的修改时间。跨子会话按轮次时间排序，并发操作的文件级精确顺序可能无法确定。
- `shell`、Python、外部工具、二进制转换等写入，如果没有留下 `fileChange`，不会自动得到 diff。本工具不推断缺失的修改前内容。
- 加载时不调用模型、不恢复会话、不读取当前文件内容，也不执行历史中的命令。因此可以查看正在其他 Codex 客户端中使用的会话。

## 偏好设置

程序保存主题、换行与并排设置、各层级的排序与行信息选择，以及上次所选的会话 ID 和文件路径。各层级独立记忆，不会把文件的排序方式套到会话上。历史正文只保留在当前进程内存中。

- macOS：`~/Library/Application Support/codex-changes/preferences.json`
- Linux：`$XDG_CONFIG_HOME/codex-changes/preferences.json`，未设置时使用 `~/.config/codex-changes/preferences.json`

文件权限为 `0600`。偏好文件损坏时，可用 `--no-state` 启动，再按需删除或修复该文件。

“跟随终端”使用终端报告的背景颜色；终端未提供颜色信息时默认深色，可用 `t` 切换。
